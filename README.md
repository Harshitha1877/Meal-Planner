# 🍽️ Meal Planner

Meal Planner is a Python-based web application designed to help users plan their meals and discover recipes easily. The application uses AI to generate recipes when a suitable recipe is not available in the existing recipe collection.

## 📌 Features

- 🍴 Plan daily meals easily
- 📚 Browse recipes from the available recipe database
- 🤖 AI-powered recipe generation
- 🔍 Search and discover recipes
- 🥗 Get personalized meal suggestions
- 📖 Uses a local recipe collection
- 💻 Simple and user-friendly web interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Ollama
- Llama 3.2
- Nomic Embed Text
- RAG (Retrieval-Augmented Generation)
